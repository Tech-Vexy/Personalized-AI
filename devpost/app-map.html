App Map · Technical Architecture

Personal AI That Remembers

A single-user thinking companion on your local device whose defining feature is long-term memory across sessions, with verified thought-signature receipts.

Architecture & Request Lifecycle

Every turn flows through a unified loop with no cloud state, no login, and a single SQLite file on disk.

1
User Input / Voice Dictation Browser captures text or speech via Web Speech API in ChatView.tsx
↓ POST /api/chat
2
Keyword Recall & Repetition Guard SQLite FTS5 bm25 MATCH searches past memories; bounded LIKE scans detect repeated requests (src/lib/memory.ts)
↓ prompt injection with session provenance
3
Model Invocation (NVIDIA NIM) Calls OpenAI-compatible endpoint for nvidia/nemotron-3.5-bolt-e4b inside structured JSON envelope (src/lib/llm.ts)
↓ JSON envelope { answer, memory_used, sources }
4
Receipts Display & Distillation Renders collapsible ThoughtSignature.tsx panel; background task distills new durable memories into SQLite

Code Tour — Three Core Locations

  • 1. The Turn Loop & Continuity Responder src/app/api/chat/route.ts

    Orchestrates the entire turn: persists incoming messages, detects "let's continue" pickups across sessions, runs repetition guards, builds the contextual prompt, and triggers background memory extraction.

  • 2. Memory Kernel & FTS5 Search src/lib/memory.ts

    Houses the core kernel functions: recallMemories (FTS5 MATCH with bm25 relevance floor of -0.6), findPriorDeliverables (repetition guard), and extractMemories (turns chats into durable facts).

  • 3. Stateless Surface & Voice Input src/components/ChatView.tsx

    Provides the calm, Gemini/Claude-inspired interface: speech-to-text dictation via the browser's native Web Speech API, legible elapsed-seconds waiting indicator (thinking… 12s), and resilient retry state.

To Change This, Start Here

Change LLM Model or Provider

Edit src/lib/llm.ts — update DEFAULT_BASE_URL or override via .env.local (NIM_MODEL, NIM_BASE_URL, NVIDIA_API_KEY).

Tune Keyword Recall Strictness

Edit BM25_FLOOR in src/lib/memory.ts (default -0.6). More negative values make recall stricter; less negative allows looser keyword matches.

Adjust Onboarding & Companion Persona

Edit SYSTEM_PROMPT or ONBOARDING_SYSTEM_PROMPT in src/app/api/chat/route.ts to adjust tone, style, or questions.

A Practice to Reuse

Structured Envelopes with Graceful Fallbacks

AI agents often struggle with strict JSON formatting over long replies. Rather than failing the user experience when a model produces stray prose or Markdown fences, this app combines a one-shot repair re-prompt with an automatic fallback to plain-text rendering (src/lib/llm.ts).

Takeaway: Always decouple structured machine metadata (receipts, citations, memory flags) from raw content delivery. Never block the user from receiving an answer just because a formatting envelope glitched.
