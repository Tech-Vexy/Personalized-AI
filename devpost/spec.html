How it works, in plain language

The interface

Browser window: chat, history drawer, mic via device speech-to-text, collapsible thought-signature panels. Follows the device's dark/light theme automatically.

The memory

One SQLite file. Sessions + messages, plus distilled long-term memory entries, each tagged with its source session and indexed by keyword search (FTS5).

The brain

One module calling z-ai/glm-5.3-flash on NVIDIA NIM (OpenAI-compatible). Recall → prompt → structured envelope → save + distill.

One process, one data file, exactly one external service — sized to prove the kernel: unified memory with judgment.

Decisions, boundaries, fallbacks

Learner choicesTypeScript + Next.js for v1 (Flutter revisited at the mobile/sync iteration — cross-device sync is a recorded north star, schema stays portable) · z-ai/glm-5.3-flash on NVIDIA NIM · Cartesia parked to Later Enhancements · theme follows the device (dark + light).
Derived detailbetter-sqlite3 + Drizzle · FTS5 recall · JSON envelope · one process · react-markdown.
Quality bar (testable)With five or more real/seeded sessions: mentioning a distinctive phrase from an old session surfaces that session's memory among the top FTS hits — and recall does not fire on unrelated messages. Verified in build with a seed script before the demo recording. Miss the bar → recorded upgrade: embeddings via NIM, schema unchanged.
Failure → fallback
  • NVIDIA call fails/hangs → error + retry; pending message held client-side until answered.
  • Envelope malformed → one repair re-prompt, then plain answer without panel — never block.
  • FTS junk / nothing clears the floor → answer with no recall; invisible is the default.
  • Day one, empty store → prompts forbid inventing history; clarifying question instead.
Simplified on purpose
  • Non-streaming JSON envelope instead of token streaming — panels need structure; typing indicator in the meantime.
  • FTS5 keywords instead of embeddings/vector DB — your recorded "keyword-based" decision.
  • Onboarding inside the normal chat pipeline — one code path proves the kernel.
  • Web Speech API dictation — free, Chromium-first, degrades elsewhere.
  • Local-only, no deployment — demo is a screen recording.
